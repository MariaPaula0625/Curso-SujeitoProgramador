# 💼 Site Portfolio

Site portfolio responsivo e profissional desenvolvido em HTML5 e CSS3.

## 🎯 Sobre o Projeto

Portfolio pessoal que apresenta:
- **Home** - Seção de boas-vindas com chamada para ação
- **Sobre** - Apresentação profissional e foto
- **Projetos** - Galeria com showcases de trabalhos
- **Contato** - CTA para orçamentos

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox)
- Google Fonts (Roboto)

## 📱 Características

✅ Design responsivo  
✅ Navegação sticky  
✅ Scroll suave  
✅ Otimizado para desktop e mobile  

## 📂 Estrutura

```
├── index.html      # Markup da página
├── style.css       # Estilos
└── images/         # Imagens do portfólio
```

## 🚀 Como usar

Abra o arquivo `index.html` no navegador.
